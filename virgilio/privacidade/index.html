Privacidade

Política de privacidade da integração Virgílio para Vercel. Versão de 22 de outubro de 2026.

English version below

Quem responde

Rafael Neves (Omnex Labs), desenvolvedor do Virgílio. Contato: rafael.fne@gmail.com.

Quais dados a integração acessa

  • A identificação do seu usuário e do seu time na Vercel.
  • Os projetos que você escolheu na instalação.
  • Os deploys desses projetos.
  • Os logs de build e de execução desses projetos.
  • Os nomes das variáveis de ambiente, sem os valores.
  • O plano e o consumo do time, só quando a permissão de cobrança existe na instalação.

Esses dados servem para o diagnóstico, para o portão de migração e para publicar de novo quando você pede. Nada além disso.

Onde os dados ficam

Só no seu computador. O acesso à Vercel fica no cofre de senhas do sistema operacional. O que o Virgílio lê da Vercel é processado na sua máquina e não é enviado para servidor do Virgílio.

Se você usa um agente de IA junto com o Virgílio, como Claude Code ou Cursor, o que você pede para esse agente analisar segue a política de privacidade do serviço dele.

O que o servidor de troca vê

Na conexão, a Vercel entrega um código de autorização. Um servidor mínimo do Virgílio, hospedado no Railway, troca esse código pelo acesso, porque a troca exige um segredo que não pode ficar no seu computador. Nesse momento o servidor vê o código e o acesso. Ele não grava nem registra nenhum dos dois e devolve o resultado direto para o Virgílio na sua máquina. O código dele é aberto no repositório do kit.

Compartilhamento

Nenhum dado é vendido ou compartilhado com terceiros.

Como revogar

Rode virgilio connections disconnect vercel ou remova o Virgílio em Integrations no painel da Vercel. O acesso para de funcionar na hora e é apagado do cofre do seu computador.

Seus direitos

Você tem os direitos previstos na Lei Geral de Proteção de Dados (Lei 13.709/2018). Como os dados ficam na sua máquina, você controla o acesso a eles e pode apagá-los quando quiser. Para qualquer pedido ou dúvida, escreva para rafael.fne@gmail.com.

Privacy policy (English)

Privacy policy for the Virgílio integration for Vercel. Version of October 22, 2026. If this version and the Portuguese one differ, the Portuguese version prevails.

Who is responsible

Rafael Neves (Omnex Labs), developer of Virgílio. Contact: rafael.fne@gmail.com.

Data the integration accesses

  • Your Vercel user and team identification.
  • The projects you chose at installation.
  • Deployments of those projects.
  • Build and runtime logs of those projects.
  • Environment variable names, without their values.
  • The team's plan and usage, only when the billing permission is part of the installation.

This data is used for diagnostics, for the migration gate and to redeploy when you ask. Nothing else.

Where the data lives

Only on your computer. The Vercel token is kept in your operating system's keychain. What Virgílio reads from Vercel is processed on your machine and is not sent to any Virgílio server.

If you use an AI agent alongside Virgílio, such as Claude Code or Cursor, whatever you ask that agent to analyze is governed by that service's privacy policy.

What the exchange server sees

When you connect, Vercel returns an authorization code. A minimal Virgílio server, hosted on Railway, exchanges that code for the access token, because the exchange requires a secret that cannot live on your computer. At that moment the server sees the code and the token. It neither stores nor logs them, and returns the result straight to Virgílio on your machine. Its source code is open in the kit repository.

Sharing

No data is sold or shared with third parties.

How to revoke

Run virgilio connections disconnect vercel or remove Virgílio under Integrations in the Vercel dashboard. Access stops working immediately and the token is deleted from your computer's keychain.

Your rights

You have the rights provided by Brazil's General Data Protection Law (LGPD, Law 13,709/2018). Since the data stays on your machine, you control access to it and can delete it at any time. For any request or question, write to rafael.fne@gmail.com.
